Unity + Vuforia 手机 AR 扫描收集游戏 Demo

核心代码在 `Assets/_Project/Scripts`。

使用方式：

1. 用 Unity 2022.3 LTS 或以上版本打开本目录。
2. 等待脚本编译完成。
3. 点击 Unity 菜单 `AR Scan Game -> Generate Demo Project` 生成示例场景、Prefab 和 ScriptableObject 数据。
4. 按 `Assets/_Project/IMPLEMENTATION_GUIDE.md` 接入 Vuforia。

项目特点：

- Unity 2022.3 LTS+
- Android
- URP
- Canvas UI
- Vuforia ImageTarget
- ScriptableObject 数据
- 简单 Manager 架构
- 事件系统通信
- 中文注释，适合学生比赛快速开发
